# Carpeta de Fuentes de Atlan

Por favor coloca aquí los archivos de la fuente **LC Mogi** (formatos `.woff2`, `.woff`, `.ttf` u `.otf`).

Asegúrate de renombrar el archivo principal de la fuente a:
* `LCMogi.woff2` (Recomendado para web)
* `LCMogi.woff`
* `LCMogi.ttf`
* O `LCMogi.otf`

Una vez colocado el archivo en esta carpeta, el mapa, los títulos y la landing page adoptarán automáticamente el estilo de la fuente de manera inmediata sin necesidad de reinstalar o reprogramar nada.
